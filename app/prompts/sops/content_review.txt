# 内容审核 SOP 模板
# 针对 1.7B 小模型优化的单步执行模板

## 模板变量
- {{content}}: 待审核内容
- {{platform}}: 目标平台
- {{constraints}}: 特殊约束

---

## 审核任务

请审核以下内容是否适合在 {{platform}} 平台发布。

待审核内容：
{{content}}

特殊约束：
{{constraints}}

---

## 审核维度

请逐一检查以下维度：

### 1. 合规性检查
- [ ] 是否包含敏感词或违禁内容
- [ ] 是否符合平台社区规范
- [ ] 是否存在版权风险

### 2. 质量检查
- [ ] 内容是否通顺流畅
- [ ] 是否有错别字或语法错误
- [ ] 逻辑是否清晰

### 3. 平台适配
- [ ] 字数是否符合平台限制
- [ ] 风格是否符合平台调性
- [ ] 标签是否恰当

---

## 输出格式

请按以下 JSON 格式输出审核结果：

```json
{
    "passed": true/false,
    "score": 0-100,
    "issues": [
        {"type": "问题类型", "description": "问题描述", "location": "问题位置"}
    ],
    "suggestions": [
        "改进建议1",
        "改进建议2"
    ],
    "summary": "一句话总结"
}
```

---

## 评分标准

- 90-100: 优秀，可直接发布
- 80-89: 良好，建议小幅修改
- 70-79: 合格，需要修改
- 60-69: 勉强，需要较大修改
- 60以下: 不合格，建议重写
